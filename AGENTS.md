# Repository instructions

- Use Node.js 24 and `npm ci`. Start with `npm run dev`. Run lint, type checking, unit tests and the production build before handing off changes. Use Chromium against `npm start` for browser tests.
- Keep service, programme and route content in `lib/site.ts`. Maintain the £2,500 minimum across all paid work, with prices strictly above it.
- Use approved experience facts and cleared assets. Keep private Google login addresses, credentials, client documents and unverified contact details out of Git and public content.
- Keep preview indexing disabled pending approval of the VAT presentation. Keep the professional email gated until the live mailbox is verified.
- Keep the discovery brief local to the browser. Obtain approval before adding data collection or third-party tracking, deploying to production, editing DNS, migrating mail or modifying account permissions and ownership.
- Document launch dependencies in `docs/`.
